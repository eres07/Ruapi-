Simple Hindi + English AI API — v1, free, with credits.
1 credit per chat call. New keys get 100 free credits. Demo brain for now — plug in a real model later with GROQ_API_KEY or SARVAM_API_KEY.

Try it here

Your answer will appear here.

API

GET  /health
POST /v1/keys            # → {"api_key": "ruapi_...", "credits": 100}
GET  /v1/credits         # Header: Authorization: Bearer <key>
POST /v1/chat            # Header: Authorization: Bearer <key>
                         # Body: {"message": "...", "language": "hi"|"en"}

curl examples

# Health
curl https://ruapi.embarko.app/health

# Get a key (100 free credits)
curl -X POST https://ruapi.embarko.app/v1/keys

# Chat in Hindi (replace KEY)
curl -X POST https://ruapi.embarko.app/v1/chat \
  -H "Authorization: Bearer KEY" -H "Content-Type: application/json" \
  -d '{"message": "नमस्ते, AI kya hai samjhao", "language": "hi"}'

# Chat in English
curl -X POST https://ruapi.embarko.app/v1/chat \
  -H "Authorization: Bearer KEY" -H "Content-Type: application/json" \
  -d '{"message": "translate hello to Hindi", "language": "en"}'

# Credits left
curl https://ruapi.embarko.app/v1/credits -H "Authorization: Bearer KEY"

Locally, replace https://ruapi.embarko.app with http://localhost:8000 — same API.
